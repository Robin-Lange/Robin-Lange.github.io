# Résumé and CV sources

Compile from this directory with `pdflatex -interaction=nonstopmode -halt-on-error recruiter.tex` for the industry résumé, `resume.tex` for the academic/research résumé, or `eth.tex` for the longer CV. The PDFs linked from the site are copies at the repository root. `Robin-Lange-Resume.pdf` remains an industry-résumé alias for older links.

The shared LaTeX content is adapted from the previously maintained local résumé source. See `ATTRIBUTION.md` for template attribution. The public documents omit past supervisors' personal contact details.
