Sensor-based validation

Truck-underride detection and test targets

Developed a collapsible truck-rear soft target and a sensor-data evaluation workflow for difficult-to-detect pre-crash and truck-underride scenarios. Collected and analyzed camera, LiDAR, and 4D-radar data to characterize detectability, identify weak radar returns and unwanted reflections, and guide target-design changes.

Compared real-truck and surrogate-target signatures using recorded measurements and MAN TruckScenes reference 4D-radar and 3D-LiDAR data. The draft manuscript investigates how trailer-underbody multipath contributes to strong radar returns and why a compact target cannot reproduce the full-length trailer signature. Camera work used BDD100K-derived rear-truck images, the Vehicle Orientation Dataset, and custom soft-target imagery: fine-tuned YOLO26l for truck-rear detection and compared YOLOv5 and visual-prompt YOLOe approaches using IoU, precision, recall, and F1.

Pre-crash perception · YOLO26l / YOLOe · Camera / LiDAR / 4D radar · Experimental validation

Autonomous aviation

Mission AI for autonomous flight

Developed a hybrid state-machine and behavior-tree approach for mission AI in Fraunhofer IVI’s ALBACOPTER research. Explicit state-transition guards organized mission phases, while reactive py_trees behaviors handled execution and interruption. The implementation ran through ROS 2 Humble nodes.

Validated defined mission transitions and emergency preemption in Fraunhofer’s in-house ALBACOPTER flight simulator. Compared the hybrid with pure state-machine and behavior-tree designs using execution time and code size, selecting the hybrid for clearer extensibility while documenting the pure behavior tree’s faster execution.

Mission AI · State machines / behavior trees · py_trees · ROS 2 Humble · Simulation validation
